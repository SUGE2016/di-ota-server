# OTA Server 工作日报

**日期:** 2026-07-23  
**工作范围:** 升级状态机宽松模式（按型号可配置）+ 管理台策略页；发版 v0.0.16  
**分支:** `experiment/relax-upgrade-state-machine`

---

## 一、目标与背景

设备固件已升成功，但因网络抖动 / 上报乱序未满足服务端严格状态迁移，被 409 拒绝，导致反复 upgrade。  
放宽默认行为，并支持按 `product_model` 在管理台切「宽松 / 严格」。

---

## 二、功能摘要（v0.0.16）

| 项 | 说明 |
|----|------|
| 默认 | **宽松**：允许回退重置、`Failed→Success` |
| 严格 | 管理台「升级策略」按型号设为 strict，保持原 409 规则 |
| Success 后 | 中间态 **忽略**（200 + `ignored`），仅 Success 幂等 |
| Success 校验 | `target_version` 必填，且须等于 `task_id` 对应包版本 |
| 存储 | `t_product_model_policy`（迁移 `009`）；无行 = 宽松 |
| UI | `/#/upgrade-policy`（菜单文案：升级策略；仅 admin） |
