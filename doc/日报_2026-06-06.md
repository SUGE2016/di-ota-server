## 二、后端修复与增强

### 1. 设备端 API（P0 行为修正）

- **check-update 只读**：决策用 `policyReportedVersion`，不再因请求版本压低库内 `reported_version`。
- **2001 响应**：`already_latest` 等场景返回 `current_version`，便于模拟器/设备侧展示。
- **report-status**：幂等命中 Success 时仍执行 `TouchDeviceReportedVersion`。
- **下载 URL**：预签名优先 `S3_PUBLIC_BASE_URL`，避免 `minio:9000` 内网 host。
- **任务 resume**：Running 时重建 `t_task_target` 快照（与 create/start 一致）。

### 2. 管理端 API

- `GET /api/v1/devices`：支持 `search` / `group` / `product_model` / `tag` / `abnormal` 筛选与分页计数。
- `GET /api/v1/devices/:device_id/upgrade-records`：设备升级历史。
- 管理端 JSON DTO：`api_dto.go` 统一映射，避免 `{String,Valid}` 泄漏。
- 路由顺序：`csv-template` 置于 `:device_id` 之前，避免误匹配。

### 3. 告警 / 集成（§七 待办）

- 迁移 `006_alerts.sql`，`GET/POST /api/v1/alerts`。
- Worker 失败率熔断、`report-status` Success/Failed 写告警（dedupe）。
- P4：`INTEGRATION_WEBHOOK_*` 异步 POST + HMAC 头。
- P5：`DEVICE_DOWNLOAD_HMAC_ENABLED` 时代理下载签名校验。

### 4. Docker

- `ota-api` / `ota-worker` 增加 `NO_PROXY=minio,...`，修复经代理访问 MinIO 502。

## 三、前端

### 1. 设备管理

- 列表：服务端筛选、异常设备开关、状态列、分页。
- 详情：升级历史 Timeline、`inconsistency_flags` 告警、「目录与 OTA 版本对比」卡片。

### 2. 告警 / 用户

- **告警中心**：接真实 API，筛选/分页/批量确认关闭，资源链跳转；长 ID 列 ellipsis。
- **用户管理**：服务端分页，筛选变更重置页码。

### 3. 列表表格 UX（全站统一）

- 新增 `utils/tableEllipsisColumn.tsx`、`tableIdLinkColumn.tsx`：长 ID / 文本列 ellipsis + Tooltip，列宽预设集中于 `TABLE_COL_WIDTH`。
- `utils/tableActionColumn.ts`：`tableLayout: fixed` + `measureTableScrollX(columns)` 驱动 `scroll.x`，保证冻结操作列与截断同时生效。
- 设备 / 用户 / 任务 / 固件包 / 告警 / 仪表盘：操作列右侧冻结；说明/资源等超长列单行省略。
- 告警表勾选列宽度计入横向滚动。

### 4. 壳层与导航

- 新增 `constants/pageMeta.ts`：各路由标题/副标题唯一来源；顶栏展示「标题 · 副标题」，内容区去掉重复标题。
- 侧栏 `OtaLogo` + 品牌区；顶栏用户信息纵向排列（JWT 用户名 + 角色中文名，避免重复展示）。
- `authStore` 从 JWT `sub` 解析用户名，登录后拉取用户目录补全角色。

### 5. 管理台 UX 清理

- 移除设备/用户页底部「能力状态 / 待迭代」开发向卡片。
- 告警中心：去掉 Mock 假数据（后接真实 API）。
- 仪表盘/顶栏：移除「外部授权未接入」常驻提示；登录页去掉 disabled SSO 按钮。
- 设备页：工具栏「设备端模拟器」入口；详情 Card 标题去重（基本信息/包信息）。

### 6. 设备模拟器

- 无升级 / 状态迁移失败时给出可操作建议。
- 表单同步 `current_version`；重复联调说明 Alert。
- 完整流程成功后更新表单版本；返回链接指向 `/devices`。
