## 二、demogo 部署

| 项 | 配置 |
|----|------|
| 入口 | `https://demogo.work/ota/`（Caddy `handle_path /ota/*`） |
| 编排 | `/opt/di-ota` + `deploy/demogo/docker-compose.demogo.yml` |
| 镜像 | `ota-api/worker/console` @ `0.0.11`（console 含 HMAC 模拟器） |
| 设备鉴权 | `DEVICE_API_AUTH_ENABLED=true` |
| 管理台 | `LOCAL_AUTH_ENABLED=true`，`OIDC_ENABLED=false` |

设备无 Authorization 时 `check-update` 返回 `401 unauthorized`（已验证）。

**provision 示例**（设备入库后）：

```bash
curl -X PUT "https://demogo.work/ota/api/v1/devices/<SN>/device-secret" \
  -H "Authorization: Bearer <admin_jwt>" \
  -d '{"device_secret":"<每台唯一 secret>"}'
```

联调 secret 示例见 `deploy/demogo/.env.example` 注释；模拟器：`/ota/#/simulator`。
