## UI 原则（2026-06-05）

管理台**不向业务用户展示**以下内容，统一保留在本文件：

- 「能力状态 / 仍待迭代」类交付说明卡片
- 「骨架 / 预留 / 后续接入」类开发备注
- 无后端支撑的 Mock 数据表格（易误认为真实告警）
- 常驻的「外部授权未接入」等技术状态条

未上线功能应使用：**诚实空状态 + 可操作的替代路径说明**（见告警中心页）。
