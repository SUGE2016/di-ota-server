## 三、架构确认（MinIO / 中间件）

| 组件 | demogo 对外 |
|------|-------------|
| postgres / redis / rabbitmq / minio 服务端口 | **不映射**宿主机 |
| 业务入口 | Caddy → `/ota/*` → console（反代 `/api/`、`/device/`） |
| 固件 PUT/GET | 预签名 URL，host 为 `S3_PUBLIC_BASE_URL`（非 MinIO 管理 API） |

demogo 原先缺 Caddy 对 `/ota-packages/*` 的反代，浏览器 PUT 预签名 URL 会 302 到首页，导致 `complete` 报 `uploaded object not found`。

**已修复（服务器 + 仓库）:**

- Caddy: `handle /ota-packages/* { reverse_proxy ota-minio:9000 }`（**勿用** `handle_path`，需保留 bucket 前缀）
- `ota-minio` 接入 `gdw-3d-bin-packing_default` 网络
- `deploy/demogo/docker-compose.demogo.yml` 持久化 minio 的 `demogo` 网络
